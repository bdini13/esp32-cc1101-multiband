# Custom RF footprints

These land patterns are project-local because the standard KiCad libraries do
not contain the exact packages.

- `Infineon_PG-TSNP-8-1`: 1.1 mm square, 0.4 mm pitch, eight 0.25 mm square
  non-solder-mask-defined copper lands with 0.25 mm circular paste apertures.
  Pin 1 is the lower-left pad in the manufacturer's top-view footprint drawing.
- `TTM_B0310J50100AHF`: 2.04 x 1.29 mm body; six 0.41 x 0.33 mm lands on a
  0.65 mm horizontal pitch and 0.98 mm row pitch. Corrected A1 TOP VIEW:
  upper row 3–2–1, lower row 4–5–6. Pin-1 mark is upper right. Do not copy
  the datasheet's bottom-view pad numbers directly onto F.Cu.
- `Abracon_ABM8_4Pin_3.2x2.5mm`: manufacturer-derived four-pad crystal land
  pattern; oscillator terminals 1/3, grounded package terminals 2/4. Added A2.

`ESP32_CC1101.kicad_sym`, generated by `../generate_symbols.py`, provides
named, electrically typed CC1101, BGS13SN8 and balun symbols. In particular,
CC1101 DGUARD is a power input and balun pins 5/6 are intentionally unconnected.

Sources:

- Infineon BGS13SN8 datasheet revision 2.4, package PG-TSNP-8-1.
- TTM B0310J50100AHF datasheet revision F, pages 1 and 4.
- Abracon ABM8 series drawing: https://abracon.com/Resonators/abm8.pdf.

All custom footprints still require a second-person pad-number/orientation review
against the physical cut-tape parts before manufacture.
